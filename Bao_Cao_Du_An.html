BÁO CÁO DỰ ÁN WEBSITE BÁN HÀNG NHK MOBILE

1. Tổng quan dự án

Tên dự án: NHK Mobile - Hệ thống thương mại điện tử chuyên doanh thiết bị di động.

Mục tiêu: Xây dựng nền tảng mua sắm trực tuyến hiện đại, hỗ trợ người dùng tìm kiếm, đặt hàng và quản trị viên quản lý kho hàng hiệu quả.

Công nghệ sử dụng:

  • Ngôn ngữ lập trình: PHP 8.x
  • Cơ sở dữ liệu: MySQL (MariaDB)
  • Giao diện: HTML5, CSS3, JavaScript (Vanilla JS)
  • Môi trường phát triển: WAMP Server

2. Cấu trúc thư mục dự án

/BE_Project-main
├── /admin # Giao diện và logic cho quản trị viên
├── /api # Các API xử lý dữ liệu (JSON/AJAX)
├── /assets # Tài nguyên tĩnh (CSS, JS, Images)
├── /includes # File dùng chung (Cấu hình DB, Header, Footer)
├── /logs # Nhật ký hoạt động hệ thống
├── index.php # Trang chủ hệ thống
├── login.php # Trang đăng nhập
├── register.php # Trang đăng ký thành viên
└── database.sql # File mã nguồn tạo cơ sở dữ liệu

3. Thiết kế Cơ sở dữ liệu

Hệ thống sử dụng cơ sở dữ liệu quan hệ với 8 bảng cốt lõi:

Tên Bảng Chức năng chính
admins Lưu thông tin tài khoản quản trị viên.
users Lưu thông tin khách hàng (Họ tên, email, SĐT, địa chỉ).
products Danh mục sản phẩm, giá, số lượng tồn kho, mô tả và thông số kỹ thuật.
orders Thông tin đơn hàng (Tổng tiền, trạng thái, phương thức thanh toán).
order_items Chi tiết từng sản phẩm trong một đơn hàng.
cart_items Lưu trữ tạm thời các sản phẩm khách hàng đã thêm vào giỏ.
reviews Lưu đánh giá và bình luận của khách hàng về sản phẩm.
wishlists Danh sách sản phẩm yêu thích của người dùng.

4. Các tính năng nổi bật

4.1. Phân hệ Khách hàng (Client)

  • Tìm kiếm thông minh: Tìm kiếm sản phẩm theo tên và danh mục thời gian thực.
  • Giỏ hàng & Thanh toán: Hỗ trợ quản lý số lượng sản phẩm và đặt hàng nhanh (COD hoặc Trả góp).
  • Đánh giá sản phẩm: Hệ thống rating 5 sao và bình luận có hình ảnh kèm theo.
  • Quản lý trang cá nhân: Theo dõi trạng thái đơn hàng và cập nhật thông tin liên lạc.

4.2. Phân hệ Quản trị (Admin)

  • Quản lý kho hàng: Thêm, sửa, xóa sản phẩm và cập nhật số lượng tồn.
  • Quản lý đơn hàng: Duyệt đơn, cập nhật trạng thái vận chuyển.
  • Bảo mật: Hệ thống phân quyền chặt chẽ giữa User và Admin.

5. Hướng dẫn cài đặt hệ thống

Để chạy dự án trên máy cục bộ, thực hiện các bước sau:

  1. Bước 1: Sao chép mã nguồn vào thư mục www của WAMP.
  2. Bước 2: Tạo database mới trong phpMyAdmin (ví dụ: nhk_mobile).
  3. Bước 3: Import file database_minimal.sql vào database vừa tạo.
  4. Bước 4: Cấu hình thông tin kết nối trong file includes/db.php.
  5. Bước 5: Truy cập địa chỉ localhost/BE_Project-main trên trình duyệt.
